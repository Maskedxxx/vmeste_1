# User Workflow — Бот «ВМЕСТЕ»

## Общая схема

```
/start → Email → Квиз (11 вопросов) → Авто-профилирование → Диагностика (3 блока) → Недельный план
                                                                ↓
                                              Чат по темам (Тело / Психика / Сексология)
```

---

## 1. Вход и регистрация

### Пользователь
- Отправляет `/start`
- Вводит email

### Бот
1. Очищает состояние FSM
2. Устанавливает состояние `waiting_for_email`
3. При получении email:
   - Валидирует формат (Pydantic EmailStr)
   - `POST /entry` → создаёт/находит пользователя в БД
   - Загружает статус (квиз, профиль, диагностика, план)
   - Переводит в состояние `ready`
   - Показывает главное меню

### Главное меню
- Пройти квиз
- Диагностика
- План на 7 дней
- Чат: Тело 🏃
- Чат: Психика 🧠
- Чат: Сексология 💕
- Статус

---

## 2. Квиз

### Пользователь
- Нажимает «Пройти квиз»
- Отвечает на 11 вопросов текстом

### Вопросы квиза
| # | Ключ | Тип | Вопрос |
|---|------|-----|--------|
| 1 | age | number | Возраст |
| 2 | gender | choice | Пол |
| 3 | relationship_status | choice | В отношениях? |
| 4 | main_concern | text | Что беспокоит? |
| 5 | sexual_insecurity | text | Что вызывает неполноценность в сексе? |
| 6 | problem_duration | text | Как давно проблема? |
| 7 | sexual_frequency | text | Частота секса/мастурбации? |
| 8 | problem_patterns | text | Паттерны усиления проблемы? |
| 9 | health_factors | text | Болезни, операции, боли? |
| 10 | attempts_history | text | Что уже пробовали? |
| 11 | course_expectations | text | Ожидания от курса? |

### Бот
1. `GET /quiz/questions` → загружает вопросы
2. Переводит в состояние `quiz_active`
3. Последовательно отправляет вопросы
4. Собирает ответы в массив
5. `POST /quiz/submit` → сохраняет в `user_memory`
6. **Автоматически** запускает обогащение профиля

---

## 3. Авто-профилирование (LLM)

### Триггер
Автоматически после завершения квиза

### Бот
1. `POST /users/{id}/profile/enrich`
2. LLM (gpt-4.1-mini) анализирует ответы квиза
3. Генерирует структурированный профиль:
   - `stress_level`: low/moderate/high/critical
   - `emotional_tone`: эмоциональное состояние
   - `key_concerns`: основные проблемы
   - `support_needs`: нужная поддержка
   - `strengths`: сильные стороны
   - `motivation_trend`: growing/stable/declining
   - `tov_style_tag`: тон общения (gentle/coaching/direct)
   - `recommended_focus`: темы для работы
   - `risk_flags`: тревожные маркеры
4. Сохраняет в `users.profile_json`

---

## 4. Диагностика

### Пользователь
- Нажимает «Диагностика»
- Выбирает релевантные теги в каждом блоке
- Нажимает «Далее» для перехода между блоками

### Бот
1. Проверяет: email ✓, квиз ✓, профиль ✓
2. `POST /users/{id}/diagnostic/run` (timeout 60s)
3. **Параллельно** запускает:
   - Диагностический агент → анализ по 3 блокам
   - Агент рекомендаций → подбор контента для каждого блока
4. Переводит в состояние `diagnostic_active`

### 3 блока диагностики

#### Блок «Тело» (body)
- Анализ физического состояния
- Рекомендуемые врачи
- Рекомендуемые анализы
- Возможные физиологические факторы
- 5-6 тегов

#### Блок «Психика» (mind)
- Анализ психологического состояния
- 5-6 тегов

#### Блок «Сексология» (sex)
- Анализ сексуальной сферы
- 5-6 тегов

### Интерфейс блока
```
[Заголовок блока]
[Анализ от LLM]
[Врачи/Анализы — если есть]

[Инлайн-кнопки с тегами]
[Кнопка «Далее»]
```

### После выбора тегов — рекомендация контента
```
Контент для блока «{название}»
[Эмпатичное сообщение]
[Название материала] — [тип]
[Описание]
[Цена] | [Длительность]
Теги: ...
Почему важно: ...
Результат: ...
Действие: ...
[Follow-up вопрос]
[Кнопка «Перейти к материалу»]
```

### Завершение диагностики
1. Сводка выбранных тегов по всем блокам
2. Сохраняет `diagnostic_done = True`
3. Предлагает построить недельный план

---

## 5. Недельный план

### Пользователь
- Нажимает «План на 7 дней»

### Бот
1. Проверяет: диагностика ✓
2. Собирает теги из результатов диагностики
3. `POST /users/{id}/week-plan/run` (timeout 60s)
4. LLM генерирует план на 7 дней

### Структура плана
Каждый день содержит:
- `day`: номер (1-7)
- `title`: название практики
- `goal`: зачем выполнять
- `instructions`: краткая инструкция
- `tags`: теги задачи
- `focus_area`: тело/психика/отношения

### Примеры практик
- Дыхательные техники
- Ведение дневника
- Социальные шаги
- Физические упражнения
- Встречи с врачами
- Медитация
- Техники расслабления

### Кэширование
План кэшируется по хэшу контекста (SHA256). При повторном запросе с тем же контекстом возвращается из кэша.

---

## 6. Статус

### Пользователь
- Нажимает «Статус»

### Бот показывает
1. **Базовые данные**
   - User ID
   - Квиз: да/нет
   - Профиль обогащён: да/нет
   - Диагностика: да/нет
   - План: готов/нет

2. **Выбранные теги** (если диагностика выполнена)
   ```
   Тело: усталость, боли, нарушения сна
   Психика: тревога, стресс, выгорание
   Сексология: низкое либидо, дискомфорт
   ```

3. **Рекомендованный контент** (если есть)
   ```
   Тело: [название] — [цена]
   Психика: [название] — [цена]
   Сексология: [название] — [цена]
   ```

4. **Превью плана** (если готов)
   ```
   День 1: [название]
   День 2: [название]
   Теги: стресс, тревога, усталость
   ```

## 7. Чат по темам (RAG)

### Пользователь
- Нажимает одну из кнопок чата: «Тело 🏃», «Психика 🧠» или «Сексология 💕»
- Пишет вопрос в свободной форме (до 2000 символов)

### Бот
1. Проверяет: пользователь авторизован (есть user_id)
2. `POST /chat` с параметрами:
   - `user_id` — идентификатор пользователя
   - `message` — текст вопроса
   - `topic` — выбранная тема (`body` / `mind` / `sex`)
3. Переводит в состояние `chat_active_{topic}`
4. RAG-агент:
   - Ищет релевантный контент в Chroma по теме
   - Формирует контекст из найденных материалов
   - Генерирует персонализированный ответ через LLM
5. Возвращает ответ с:
   - Текстом ответа в эмпатичном тоне
   - Ссылками на материалы психолога
   - Follow-up вопросом для продолжения диалога

### Интерфейс чата
```
[Кнопка темы нажата]

Пользователь: Как справиться со стрессом на работе?

Ассистент: [Персонализированный ответ...]

📚 Материалы по теме:
• [Название материала 1]
• [Название материала 2]

💬 Хотите узнать о техниках дыхания для снятия напряжения?
```

### Особенности
- Чат работает в рамках сессии (session_id)
- История сообщений сохраняется в chat_history
- Каждая тема создаёт отдельную сессию `chat_body` / `chat_mind` / `chat_sex`
- Контекст формируется из контента психолога, фильтрованного по теме

## FSM-состояния

| Состояние | Описание | Допустимые действия |
|-----------|----------|---------------------|
| `waiting_for_email` | Ожидание email | Ввод email |
| `ready` | Главное меню | Квиз, Диагностика, План, Чат, Статус |
| `quiz_active` | Прохождение квиза | Текстовые ответы |
| `diagnostic_active` | Прохождение диагностики | Выбор тегов, «Далее» |
| `chat_active_body` | Чат по теме «Тело» | Текстовые вопросы, «Назад» |
| `chat_active_mind` | Чат по теме «Психика» | Текстовые вопросы, «Назад» |
| `chat_active_sex` | Чат по теме «Сексология» | Текстовые вопросы, «Назад» |

## API-вызовы бота

| Этап | Метод | Endpoint |
|------|-------|----------|
| Вход | POST | `/entry` |
| Квиз (загрузка) | GET | `/quiz/questions` |
| Квиз (отправка) | POST | `/quiz/submit` |
| Профилирование | POST | `/users/{id}/profile/enrich` |
| Диагностика | POST | `/users/{id}/diagnostic/run` |
| План | POST | `/users/{id}/week-plan/run` |
| **Чат по темам** | POST | `/chat` |
| Статус | GET | `/users/{id}` |

## Ограничения

- Теги диагностики: до 5 на блок
- Вопросы квиза: 11
- План: ровно 7 дней
- Timeout API: 10-60 сек
